# JoJo 主题 | JoJo Theme

这是一个为 Visual Studio Code 设计的个人主题，灵感来源于 JoJo 的奇妙冒险系列。深色主题，该主题旨在提供一种独特且舒适的代码编辑体验，同时保持良好的可读性和视觉吸引力。

This is a personal theme for Visual Studio Code, inspired by the JoJo's Bizarre Adventure series. A dark-themed color scheme designed to provide a unique and comfortable coding experience while maintaining excellent readability and visual appeal.

## 主题特点 | Theme Features

- 丰富的配色方案，适合多种编程语言。
- 精心设计的语法高亮，提升代码可读性。
- 适配深色模式，保护眼睛并减少视觉疲劳。

- A rich color palette optimized for various programming languages.
- Carefully crafted syntax highlighting to improve code readability.
- Dark mode optimized for eye protection and reduced visual fatigue.

## 针对 Python 的适配 | Python Adaptation

- **类 (Classes)**：针对 Python 类进行了专门的配色和样式优化。
- **变量 (Variables)**：区分大小写变量，确保代码清晰易读。
- **函数 (Functions)**：函数名和参数具有独特的高亮效果。
- **装饰器 (Decorators)**：装饰器的语法高亮经过精心设计，便于识别。

- **Classes**: Specifically optimized color scheme and styling for Python classes.
- **Variables**: Case-sensitive variable highlighting for clarity.
- **Functions**: Distinctive highlighting for function names and parameters.
- **Decorators**: Carefully designed syntax highlighting for easy identification.

## 安装与使用 | Installation & Usage

1. 打开 Visual Studio Code。
2. 进入扩展市场，搜索 "jojo-theme"。
3. 安装即可。

4. Open Visual Studio Code.
5. Navigate to the Extensions Marketplace and search for "jojo-theme".
6. Install and activate the theme.
